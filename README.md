# LYRIC VIDEO EDITOR

白背景・黒文字の歌詞動画を作るWebアプリです。音声認識は行いません。音源・歌詞はブラウザ内で処理し、サーバーに送信しません。

## 使い方

1. 「曲ファイルを選択」から音源を読み込みます。
2. 「歌詞をまとめて配置」で曲名と歌詞を入力します。空行が次の表示ブロック、通常の改行は同じ画面の改行です。配置の開始・終了時刻を指定できます。既存のテキストを置き換える操作は元に戻せます。
3. 個別追加する場合は波形をクリックし、テキストを入力します。追加できる場所には「＋」と「テキストを追加」が表示されます。曲名も同じ歌詞トラックに並び、「曲名」ラベルで区別します。同時表示には「＋ トラック」で別の歌詞トラックを追加し、ブロックを上下にドラッグするか「配置・時間」で移動先を選びます。
4. バー全体をドラッグして移動し、左右の端で表示開始・終了を調整します。通常は内部の表示タイミングを元の時刻に保ち、Ctrlを押しながら端をドラッグすると表示タイミングも長さに合わせて伸縮します（先頭の要素はブロック先頭に固定）。上部の時間目盛りはクリック・ドラッグで再生位置を移動できます。Ctrl＋ホイール上下でカーソル位置を基準に拡大・縮小、スライダーではインジケーターを中央にして拡大・縮小します（曲の端ではスクロール可能範囲内に収めます）。バー選択後の左右キーは1フレーム分、Shift＋左右キーは1秒分移動します。
5. 右側でフォント、サイズ、太さ、文字間、行間、揃え、位置を変更できます。文字間は動画上のpx、行間は文字サイズに対する倍率です。プレビュー内の枠もドラッグできます。「グリッド表示」「グリッドに吸着」は独立した切り替えで、間隔は動画上の20px・30px・60pxを選択できます。吸着はテキストブロックの中心が基準です。揃えはブロック内の行揃えです。
6. 通常はマスターフェードを使用します。タイムライン下部に加え、「マスターを使用」がオンのブロック設定からも共通のイン・アウト時間を変更できます。両方の入力欄は同期し、マスターを使用する全ブロックに反映します。「マスターを使用」を解除したテキストには個別のイン・アウト時間が適用されます。再びチェックするとマスターに戻ります。フェード合計が表示時間を超えた場合、同じ比率で短縮します。0秒は即時の表示・非表示です。
7. 「MP4を書き出す」で動画を作成し、完成後「MP4を保存」を押します。H.264 / AAC、1920×1080、30fps、ステレオで書き出します。音源の作者名などのメタデータはコピーしません。プレビュー音量は書き出しに影響しません。

## 文字組み・表示タイミング

「文字」タブで横組み／縦組みを切り替えます。縦組みは右から左へ改行し、和文を正立、英数字を横倒しに配置します。プレビューで文字を範囲選択すると、フォント・サイズ・太さ・文字間・ベースラインシフト・文字回転を部分的に変更できます。ベースラインシフトの正値は横組みで上、縦組みで右へ移動します。数値の単位は動画上のpx、文字回転は度です。

書式が混在する項目は空欄になります。混在した数値欄で上下キーまたはスピンボタンを使うと、選択範囲内（範囲選択がなければブロック全体）の最大値を基準に値を増減して統一します。通常の数値入力では入力した値に統一します。プレビューの選択枠で矢印キーを押すと1px、Shiftと併用すると10px移動します。

「配置・時間」→「表示タイミングを編集」から、ブロック内の行・単語（空白区切り）・文字に開始点を作成できます。日本語の任意の単語は直接編集で範囲選択し、「選択文字を現在位置で表示」で指定します。最初の要素はブロック先頭の0秒に固定されます。2つ目以降の開始点はブロック先頭からの相対秒数で保存され、歌詞ブロック内の黄色いマーカーをドラッグするか数値を入力して調整します。「追加して残す」「順に切り替える」の両方式を使えます。レイアウトは固定され、まだ表示しない文字の場所も確保されます。開始点のない範囲は通常どおり表示されます。段階表示にもブロックのフェード設定（マスター使用時はマスターフェード）を適用します。「追加して残す」は各開始点でフェードインし、ブロック末尾でフェードアウトします。「順に切り替える」は次の開始点までにフェードアウトします。表示区間よりフェード合計が長い場合は同比率で短縮します。

同じ歌詞トラックでは、ブロック移動時に隣接ブロックを押しのけます。上下にドラッグすると別トラックへ移動でき、移動先で重なるブロックは後ろへ押し出します。曲末に収まらない場所への移動は適用されません。曲の端に達すると移動を制限し、長さを保ちます。左右端を伸ばした場合は重なる部分だけを切り取り、覆われたブロックの残りは元の時刻を保ちます。完全に覆われたブロックは削除され、どちらの操作も元に戻せます。旧ファイルに重なりがある場合は、読み込み時に別トラックへ引き継ぎます。

PCではヘッダーとフッターを含めて画面内に収まり、歌詞トラックを3つ以上にした場合にページが縦に伸びます。スマートフォンなど幅の狭い画面では、操作欄を縦に並べるためスクロールできます。

## 保存・再開

「保存」で `.tomei.json` に歌詞と編集設定（文字間・行間を含む）を保存します。音源自体は含めません。「開く」で編集データを読み込み、元の音源を選び直すと再開できます。旧版のファイルも開けます。グリッド表示・吸着・ズームはその画面での操作設定で、ファイルには含みません。端末内の一時保存からの復元も用意していますが、ブラウザデータ削除で消えるため、ファイル保存を推奨します。

Space：再生・停止、Ctrl/Cmd+Z：元に戻す、Ctrl/Cmd+Shift+Z：やり直す、Ctrl/Cmd+S：保存、Delete：選択したテキストを削除。文字入力中は通常の入力操作を優先します。

## ブロック編集

- タイムラインまたはプレビューでブロックを選び、Ctrl/Cmd+C → Ctrl/Cmd+Vでコピー・貼り付けできます。内容・書式・フェード・表示時間を複製し、再生インジケーターの時刻を配置開始にします。複数ブロックでは相対的な時間差も保持します。曲末を超える場合は、全体が収まる位置に戻して配置します。
- プレビューのテキストをダブルクリックすると、その場所で直接編集できます。Enterで改行、EscまたはCtrl/Cmd+Enter、枠の外のクリックで編集を終了します。文字編集中のコピー・貼り付けは通常の文字操作になります。日本語の変換中はブロック操作を行いません。
- 選択枠の四隅をドラッグすると、反対の角を基準に文字サイズを変更します（16〜240px）。
- Alt＋左右キーで、ブロック選択中は文字間を1pxずつ調整します。直接編集中はカーソル位置の2文字間のカーニングを1pxずつ調整し、文字範囲を選択している場合はその範囲内の文字間を調整します。行をまたぐ文字間や、絵文字・濁点の途中は分割しません。カーニングも保存・書き出しに反映します。
- タイムラインでShift＋クリックすると複数選択・選択解除できます。最初に選んだブロックを太枠で示し、右側に基準のテキストと整列ボタンを表示します。左端・水平中央・右端・上端・垂直中央・下端を揃えられ、基準のブロックは動かしません。整列は動画上の表示位置に適用し、表示タイミングは維持します。複数選択のコピー・削除にも対応しています。

複数選択中の「文字サイズを揃える」では、最初に選んだブロックの文字サイズを他の選択ブロックに適用します。位置・タイミング・その他の書式は維持します。

各編集操作は「元に戻す」で取り消せます。直接編集中もCtrl/Cmd+Z・Ctrl/Cmd+Shift+Zが使えます。画面右上の「ヘルプ」から、主な操作とショートカットを確認できます。

## フォント・規定

Noto Sans JP、Noto Serif JP、M+（M PLUS 1）を同梱しています。M+フォントは [M+ FONTS](https://mplusfonts.github.io/) のM PLUS 1を使用しています。MSゴシック・MS Pゴシック・MS明朝・MS P明朝・ヒラギノ角ゴ・ヒラギノ明朝・ヒラギノ丸ゴは、端末に存在する場合に選択できます。太さは選択範囲のフォントで使えるものだけを表示します。Noto Sans JP・M+は100〜900、Noto Serif JPは200〜900に対応し、「数値指定…」で中間値も入力できます。ヒラギノ各書体はW0〜W9のうち端末で読み込めたウェイトを表示します。MS系は標準のみで、太字の文字をMS系へ変更した場合や、旧データのMS系の太字は標準になります。別の端末で読み込んだ際に存在しないフォントは通知してNoto Sans JPに置き換えます。文字数が多いときは自動折り返しせず、入力した改行を維持します。書き出し前には画面からのはみ出しと表示時間の重なりを知らせます。

非公式ツールです。クレジットや歌詞内容を自動判定する機能はありません。参加前に [公式規定](https://site.nicovideo.jp/mushokutomeisai/) と [公式FAQ](https://site.nicovideo.jp/mushokutomeisai/faq/) を確認してください。プレビューのグリッド・選択枠・曲名ラベルなどの編集UIは動画には入りません。

## 構成・ライセンス

公開版にはGoogle Analytics 4（測定ID：`G-Q9S5E2T144`）を導入しています。`dist/analytics.js` でGoogleタグを初期化し、ページ閲覧などのアクセス状況を計測します。音源・歌詞の内容・編集データ・書き出した動画を送信する独自イベントは追加していません。Googleシグナルと広告パーソナライズ用シグナルは無効にしています。`localhost`・`127.x.x.x`・`[::1]`・ファイル直接表示ではタグを読み込まないため、ローカルの開発・編集は計測しません。公開用の直下の `index.html` にも、`npm run build` で反映されます。

フレームワークを使わないHTML/CSS/JavaScriptです。`dist/app.js` がUI、`dist/core.js` が編集データ、`dist/renderer.js` がプレビューと書き出し共通の描画処理です。`src/exporter.js` をビルドし、必要なときだけ読み込む `dist/vendor/exporter.js` を生成します。

操作画面にはInter（英数字）とNoto Sans JP（日本語）のWebフォントを同梱しています。動画用フォントの選択には影響しません。

MediabunnyとAAC拡張はMPL-2.0、Inter・Noto・M+フォントはSIL Open Font Licenseです。同梱ライセンスは `dist/licenses` と `dist/fonts/*/LICENSE` にあります。Mediabunnyのソースは https://github.com/Vanilagy/mediabunny 、フォント配布元は https://github.com/fontsource/fontsource です。
